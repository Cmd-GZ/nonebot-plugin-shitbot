# /au2rc

**把音频文件转换成语音发送**

## 使用方式

```bash
(回复一条音视频文件或视频) /au2rc [群号 ...]
```

若是视频文件或视频，bot会将它转换成音频后发送

若在命令后填写群号，bot会将音频发送到指定群；不填写则会发送到当前会话

## 示例

```bash
# 回复音频文件，发到当前会话
(回复音频文件) /au2rc

# 回复视频，发到群 114514
(回复视频) /au2rc 114514

# 回复音频，广播到多个群
(回复音频) /au2rc 114514 1919810
```

## 注意

- 被回复的消息必须是一条**音频文件**或**视频**消息，否则会提示「未检测到有效回复」
- 使用该命令需要 `au2rc` 权限条目通过（默认允许，可在 `/perm` 中关闭）
- 指定群号需要 `au2rcboardcast` 权限条目通过（**默认关闭**，需先用 `/perm` 开启）；没有该权限时群号会被忽略，只发当前会话
