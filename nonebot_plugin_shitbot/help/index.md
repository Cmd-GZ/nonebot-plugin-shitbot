# Shitbot

## 可用命令

| 命令 | 说明 |
|------|------|
| `/session` | 管理当前会话 |
| `/perm` | 权限查看与管理 |
| `/help` | 显示帮助信息 |
| `/convert` | 收集图片并批量处理后发送 |
| `/randpic` | 随机获取二次元图片 |
| `/涩图` | `/randpic` 的别名 |
| `/pixiv` | 根据Pixiv ID从P站获取图片 |
| `/bilibili` | 解析并下载 B 站视频 |
| `/shitpost` | 将消息转发到多个群聊 |
| `/md2pic` | 将 markdown 文本转换为图片输出 |
| `/autoreply` | 自动回复系统管理 |

## 示例

```bash
/help help     查看 /help 的用法
/help convert  查看 /convert 的用法
```
