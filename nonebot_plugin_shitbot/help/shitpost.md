# /shitpost

**将消息转发到多个群聊**

## 使用方式

```bash
/shitpost start [选项] <群号 ...>
    开始转发，之后你发送的所有消息都会转发到指定群

/shitpost stop
    停止转发
```

## 选项

| 选项 | 说明 |
|------|------|
| `--min <时间>` | 最短转发间隔时间, 单位为秒, 默认为 0 |
| `--max <时间>` | 最长转发间隔时间, 单位为秒, 默认为 0 |

若 max 值或 min 值为负数, 则会被忽略

若 max 值小于 min 值，则不会延迟转发

## 示例

```bash
/shitpost start 123456 789012
(发送消息...)
/shitpost stop
```

## 注意

- 此命令默认仅限私聊使用
- 至少需要指定 1 个群号
- Bot 必须已经在目标群中
- 支持文本、图片、视频消息以及合并转发消息
