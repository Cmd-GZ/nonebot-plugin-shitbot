# 参数解析

BotArgParser 是 shitbot 的命令解析器。本文档说明如何使用该解析器及其行为，囊括如何定义命令、解析 argv，以及如何判断输入合法性。

---

## 术语定义

| 术语 | 定义 |
|---|---|
| **parser** | `BotArgParser` 实例，负责解析一条命令 |
| **argv** | 用户输入按空格分割的字符串 `list[str]`，如 `["-n", "5", "start", "-v"]` |
| **选项 (option / opt)** | 由 `add_opt("name")` 注册的命名参数，分为带值选项和标志选项 |
| **带值选项** | `required=True` 的选项，出现时后跟一个**选项值**，如 `-n 5` |
| **标志选项 (flag)** | `required=False` 的选项，不跟选项值 |
| **选项值** | 紧跟在带值选项后面的那个 argv 元素。解析后存入 `opts_value` |
| **自由参数** | argv 中不是子命令、不是选项、也不是选项值的元素 |
| **子命令 (subcmd)** | 通过 `add_subparser("name")` 注册的嵌套解析器 |
| **子解析器 (subparser)** | 子命令对应的独立 `BotArgParser`，有自己的选项和规则，与父 parser 完全隔离 |

## 行为

### 1. 元素归属

parser 从左往右扫描 argv，只判定各元素属于子命令、选项、选项值还是自由参数。

#### 规则 1 — 子命令

匹配到已注册的子命令名时，该元素及其后面所有元素全部切走，交给子 parser 独立解析。父 parser 只能看到此前的元素。

```
argv: start -n 5
  → 子命令: start
  → 父 parser 的 argv: （空）
  → 子 parser 的 argv: -n 5

argv: -n 5 start -v
  → 子命令: start
  → 父 parser 的 argv: -n 5
  → 子 parser 的 argv: -v

argv: a b start c d
  → 子命令: start
  → 父 parser 的 argv: a b
  → 子 parser 的 argv: c d
```

#### 规则 2 — 选项

匹配到已注册的选项名时，按以下优先级处理：

**2a — 出现次数上限。** 该选项已出现次数达到 `max_appeared` 时，不再尝试识别。此后该选项名及其后继元素全部落入规则 3。

```
已知 -n 是带值选项 (type=str, max_appeared=2)

argv: -n 1 -n 2 -n 3
  → 前 2 个 -n: 进入规则 2b/2c
  → 第 3 个 -n 及其后 "3": 落入规则 3, 成为自由参数
```

**2b — 带值选项** (`required=True`)。将紧跟在后的一个元素变为选项值。（若无后继元素则非法，第 2 节详述。）

```
已知 -n 是带值选项 (type=str)

argv: -n 5
  → 识别为选项 -n, 选项值为 "5"

argv: -n
  → 带值选项缺选项值（非法，见 2.3）

argv: -n -v
  → 识别为选项 -n, 选项值为 "-v"
  → 即使 -v 已被注册, 该 -v 成为选项值后不再被识别为选项
```

**2c — 标志选项** (`required=False`)。不影响任何后继元素。每出现一次计数 +1。

```
已知 -v 是标志选项

argv: -v
  → 识别为选项 -v

argv: -v -v -v
  → 各元素依次识别为选项 -v，共出现 3 次
```

---

#### 规则 3 — 自由参数

不满足规则 1 和规则 2 的元素，一律归类为自由参数。

```
argv: -n 5 -r off alice bob
  → 选项: -n (选项值为 "5"), -r (选项值为 "off")
  → 自由参数: "alice", "bob"

argv: alice bob
  → 无选项
  → 自由参数: "alice", "bob"
```

---

### 2. 合法性约束

属性归属完成后，parser 对每个元素做合法性校验。以下说明什么情况下 argv 非法。

#### 2.1 `need_subcmd`

若 `set_rule(need_subcmd=True)` 但整条 argv 中未匹配到任何子命令 → 非法。

```
已知 need_subcmd=True，注册了子命令 "start"

argv: -n 5         ❌  缺少子命令
argv: start -n 5   ✅
```

#### 2.2 `necessary`

标记为 `necessary=True` 的选项，必须在 argv 中出现至少一次，否则非法。

```
已知 -n, -r 都是 necessary=True

argv: -n 5              ❌ 缺少 -r
argv: -n 5 -r off       ✅
```

#### 2.3 带值选项 — 缺选项值 / `type` / `choice`

带值选项的选项值须通过三重校验：

1. 存在：选项后至少有一个元素可吃（否则非法）。
2. 类型：`type(value)` 必须成功。
3. 选择（若有 `choice`）：值必须在 `choice` 集合内。

```
已知 -n (type=int, choice=[1,2,3,5])

argv: -n       ❌  缺选项值
argv: -n abc   ❌  类型校验失败
argv: -n 4     ❌  choice 校验失败
argv: -n 5     ✅
```

`choice` 仅对带值选项生效：标志选项不取选项值，无值可校验。

#### 2.4 自由参数 — 位置

自由参数必须出现在所有选项（及选项值）之后。第一个选项之前不能有自由参数，选项之间也不能夹自由参数。

```
argv: alice -n 5         ❌  在第一个选项之前
argv: -n 5 alice -r off  ❌  夹在选项之间
argv: -n 5 -r off alice  ✅
argv: alice bob          ✅  无选项, 全是自由参数
```

#### 2.5 自由参数 — 数量与类型

自由参数个数必须在 `set_rule()` 指定的 `[min, max]` 范围内。每个自由参数（设索引为 i ）必须能通过 `types[min(i, len-1)]` 对应的类型的转换。

```
已知 set_rule(min=1, max=2, types=[int])

argv: 42          ✅  数量 1, 类型 int
argv: 42 100      ✅  数量 2, 类型 int
argv:             ❌  数量 0 < min=1
argv: 42 100 7    ❌  数量 3 > max=2
argv: abc         ❌  类型校验失败
```

---

### 3. 取值

归属和合法性都通过后，parser 将各元素转换成最终结果。所有结果值均为 `list[Any]` 类型。

#### 3.1 带值选项

每出现一次，选项值经 `type` 转换后追加到列表中。存入`parser.opts_value["<选项名>"]`中。

```
已知 -n 是带值选项 (type=int)

argv: -n 5 -n 3
  → opts["-n"] = [5, 3]（int）
```

#### 3.2 标志选项

出现 N 次则值为 `[N]`。每多出现一次计数 +1。存入`parser.opts_value["<选项名>"]`中。

```
已知 -v 是标志选项 (default 未指定), --all 是标志选项 (default=[0])

argv: -v -v
  → opts["-v"] = [2], opts["--all"] = [0]
```

#### 3.3 缺省值

选项在 argv 中**完全没有出现**时，解析结果取注册时指定的 `default`（不传则 `[]`）。只要出现过至少一次，就不会使用 `default`。

```
已知 -v 是带值选项 (default=[”foo“]), --all 是标志选项 (default 未指定])

argv: -v -v
  → opts["-v"] = ["-v"], opts["--all"] = []

argv: --all
  → opts["-v"] = ["foo"], opts["--all"] = [1]
```

#### 3.4 自由参数

按索引取 `types[min(i, len-1)]` 转换后存入 `parser.value`。

```
已知 set_rule(types=[str, int])

argv: foo 42 bar
  → parser.value = ["foo", 42, "bar"]（str, int, str）
```

#### 3.5 子命令

子 parser 独立执行上述全部取值过程，结果写入其自身的 `opts_value`、`value`、`subcmd`。父子 parser 取值互不干扰。

## API 参考

### 创建 parser

```python
parser = BotArgParser()
```

### `set_rule()` — 设定自由参数的约束

```python
parser.set_rule(*, min=0, max=None, types=[str], need_subcmd=False)
```

| 参数 | 默认值 | 作用 |
|---|---|---|
| `min` | `0` | 至少需要几个自由参数 |
| `max` | `None` | 最多允许几个自由参数 (`None` = 不限) |
| `types` | `[str]` | 自由参数的类型列表。第 i 个用 `types[min(i, len-1)]` 转换，转换失败则非法 |
| `need_subcmd` | `False` | 若 `True`，argv 中必须出现子命令名 |

### `add_opt()` — 注册选项

```python
parser.add_opt("名称", *,
    required=False,        # True=带值选项, False=标志选项
    necessary=False,       # 是否强制出现
    choice=None,           # list[str] | None，选项值的合法集合
    type=str,              # 选项值的 Python 类型
    max_appeared=1,        # int | None，最多匹配次数
    default=None,          # list[Any] | None，缺省值
)
```

| 参数 | 含义 |
|---|---|
| `name` | 选项在 argv 中的匹配字符串，如 `"-n"`、`"--all"` |
| `required` | `True`：选项后必须跟一个选项值；`False`：标志选项 |
| `necessary` | `True`：argv 中必须出现此选项，否则非法 |
| `choice` | 仅对带值选项有效——要求选项值在集合内 |
| `type` | 选项值的类型，用于校验和转换 |
| `max_appeared` | 最多匹配几次。超出后该选项名变为自由参数。默认 `1`，`None` 不限 |
| `default` | 选项**完全不出现**时填入 `opts_value` 的值，`list[Any]`。不传则 `[]` |

### `add_subparser()` — 注册子命令

```python
sub = parser.add_subparser("名称")
```

- 若同名子 parser 已存在，返回同一实例（可在多处追加选项）
- 返回的 `sub` 可继续调用 `set_rule()`、`add_opt()`、`add_subparser()`

### 解析

```python
parser.is_valid(argv)    # bool，失败时通过 parser.err 获取错误原因
parser.parse_argv(argv)  # 合法时填充以下属性，非法时抛 ValueError

# 解析结果
parser.opts_value   # dict[str, list[Any]]   选项名 → 选项值列表
parser.value        # list[Any]              自由参数列表
parser.subcmd       # str | None             匹配到的子命令名
parser.subparsers   # dict[str, BotArgParser] 所有子解析器（只读）
parser.subparser    # BotArgParser | None    当前匹配到的子解析器（只读）
parser.err          # str                    最近一次 is_valid 失败的原因
```

## 完整示例

```python
parser = BotArgParser()
parser.set_rule(min=0, max=None, types=[str])
parser.add_opt("-n", required=True, type=int, default=[1])
parser.add_opt("-r", required=True, choice=["off","on","only"], default=["off"])
parser.add_opt("-v", required=False)
parser.add_opt("-s", required=False, default=["regular"])
parser.add_opt("-t", required=False, type=str, default=[])

start = parser.add_subparser("start")
start.set_rule(max=0)

stop = parser.add_subparser("stop")
stop.set_rule(max=0)
```

| 输入 | `is_valid` | 解析结果 |
|---|---|---|
| `-n 5 -r off` | ✅ | 选项: -n[5] -r["off"]; 自由参数: [] |
| `-n 1 -r on -v -v extra` | ✅ | 选项: -n[1] -r["on"] -v[2]; 自由参数: ["extra"] |
| `-r off` | ✅ | 选项: -r["off"], -n 未出现取 default=[1] |
| `-n 5 -r off -v` | ✅ | 选项: -n[5] -r["off"] -v[1]; 自由参数: [] |
| `-n 5 -r off -v 1` | ✅ | 选项: -n[5] -r["off"] -v[1]; 自由参数: ["1"] |
| `start` | ✅ | 子命令: start |
| `-r off start` | ✅ | 子命令: start; 父选项: -r["off"]; 子 parser 处理空串 |
| `-n` | ❌ | 带值选项缺选项值 |
| `-n abc` | ❌ | 选项值无法转为 int |
| `-v 1 -n 5` | ❌ | `1` 夹在选项 `-v` 和 `-n` 之间（规则 3） |
| `-r auto` | ❌ | 选项值 "auto" 不在 choice 中 |
| `extra -n 5` | ❌ | 自由参数在选项前 |
