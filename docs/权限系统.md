# 权限系统

shitbot 的权限系统基于**用户权限组 / 群组权限组 + 权限条目**的模型，通过 `/perm` 命令进行管理。

---

## 1. 基本概念

权限相关持久化文件存放在 `config/permissions/` 目录下（`config` 为 `config.yaml` 中 `bot_base` 配置所指向的 `config/` 目录，用于存放一般设置文件；其他持久化文件存放于 `data/`、`cache/` 等目录，不在此赘述）。

### 用户权限组 (`permissions/users.yaml`)

`dict[str, list[str]]` — 组名到用户 ID 列表的映射。

### 群组权限组 (`permissions/groups.yaml`)

`dict[str, list[str]]` — 组名到群组 ID 列表的映射（私聊用 `"private"` 表示）。

### 权限条目 (`permissions/entries.yaml`)

`dict[str, dict]` — 由开发者创建的权限条目集合。每个条目提供一个可被 `check_permission` 使用的权限判断规则。条目的运用方式由开发者自行决定，无硬性规定。

条目结构（`_ENTRY_SCHEMA`）：

```yaml
<条目名>:
  description: str           # 条目描述
  users:
    is_white: bool           # 用户白名单模式
    whites: [str]            # 白名单用户权限组列表
    blacks: [str]            # 黑名单用户权限组列表
  groups:
    is_white: bool           # 群组白名单模式
    whites: [str]            # 白名单群组权限组列表
    blacks: [str]            # 黑名单群组权限组列表
```

## 2. 权限判定

### 布尔表达式（预检）

`precheck_permission(entry, group_id, user_id)` 按以下布尔表达式进行基础判断：

`(用户，群组)` 的权限 = **用户权限表达式 and 群组权限表达式**。

```
用户权限 = (not is_white or user ∈ whites 的任一组的成员)
           and user ∉ blacks 的所有组的成员

群组权限 = (not is_white or group ∈ whites 的任一组的成员)
           and group ∉ blacks 的所有组的成员
```

- 黑名单优先级最高：命中即否决。
- 白名单模式关闭（`is_white = false`）时，无条件放行用户/群组维度。
- 白名单模式开启（`is_white = true`）时，必须属于白名单组之一才放行。

### API

| 方法 | 说明 |
|---|---|
| `permissions.check_permission(entry, group_id, user_id)` | 标准检查：`admins` 组用户直接通过 |
| `permissions.owners_check_permission(entry, group_id, user_id)` | `owners` 组用户直接通过（用于 `/perm` 管理命令） |

### 特殊用户权限组

以下用户权限组具有硬编码的特殊权限：

| 组名 | 成员来源 | 权限 |
|---|---|---|
| `owners` | `config.yaml` 的 `owners` 字段，启动时自动同步到 `users["owners"]` | 拥有 `/perm` 所有管理命令的权限 |
| `admins` | `users.yaml` 中 `admins` 组 | 拥有**所有条目**的权限，但不能通过 `/perm` 修改 `admins` 或 `owners` 组 |

习惯上的特殊用法（非硬编码，取决于条目的 `blacks`/`whites` 配置）：

- `banned`：在各条目的黑名单中被引用，用于完全禁止某用户/群组使用对应命令。

## 3. `/perm` 命令

### 通用选项

以下选项在多个子命令中复用，含义一致：

| 选项 | 含义 |
|---|---|
| `-t <类型>` | 指定操作对象类型：`user`（用户权限组）、`group`（群组权限组）、`entry`（权限条目） |
| `-U <组名>` | 用户权限组名称（可多次出现） |
| `-G <组名>` | 群组权限组名称（可多次出现） |
| `-E <条目名>` | 权限条目名称（可多次出现） |
| `-u <用户ID>` | 用户 ID（可多次出现） |
| `-g <群组ID>` | 群组 ID（可多次出现） |
| `--all` | 输出详细信息 |
| `-s <on\|off>` | 开关状态 |
| `-A <权限组名>` | 将被添加的权限组（可多次出现） |
| `-R <权限组名>` | 将被移除的权限组（可多次出现） |

### 普通用户自查

列出所有权限条目及当前用户的权限状态（无需管理权，仅需 `perm` 条目权限）。

```
/perm check
```

### 查看列表

列出指定类型的所有组/条目名称。`--all` 同时输出详细信息。

```
/perm list -t <类型> [--all]
```

### 查看权限组信息

查看指定组/条目的详细信息。可混用多个选项。

```
/perm info [-U <组名> ...] [-G <组名> ...] [-E <条目名> ...]
```

### 增减权限组

创建/删除用户权限组或群组权限组。已存在 / 不存在时发出警告并跳过。

```
/perm create [-U <组名> ...] [-G <组名> ...]
/perm delete [-U <组名> ...] [-G <组名> ...]
```

### 向权限组添加/移除成员

第 i 个 `-U`/`-G` 对应第 i 个 `-u`/`-g`。已存在 / 不存在时发出警告并跳过。

```
/perm add    [-U <组名> ...] [-G <组名> ...] [-u <用户ID> ...] [-g <群组ID> ...]
/perm remove [-U <组名> ...] [-G <组名> ...] [-u <用户ID> ...] [-g <群组ID> ...]
```

### 开关白名单模式

管理权限条目的白名单/黑名单配置。`-t` 指定修改用户侧（`user`）还是群组侧（`group`）。支持多个条目名。

```
/perm entry -t <user|group> whitelist -s <on|off> <条目名...>
```

### 增减白名单/黑名单权限组

向条目的白名单或黑名单添加（`-A`）/移除（`-R`）权限组。二者可混用。

```
/perm entry -t <user|group> whites [-A <权限组名> ...] [-R <权限组名> ...] <条目名...>
/perm entry -t <user|group> blacks [-A <权限组名> ...] [-R <权限组名> ...] <条目名...>
```

### 权限控制

| 命令 | 所需权限 |
|---|---|
| `/perm check` | `perm` 条目 |
| `/perm` 其余所有子命令 | `permmanager` 条目 或 用户在 `owners` 组中 |

非 owners 用户无法通过 `/perm` 修改 `admins` 和 `owners` 用户权限组。

### 关于编辑 owners 组

`owners` 用户可以通过 `/perm` 命令编辑甚至删除 `owners` 组。**删除 `owners` 是危险操作**：删除后 `config.yaml` 中的 `owners` 字段将被设为 `null`，bot 重新加载后 `owners` 组变为空，将无法再使用 `/perm` 管理命令。

**修复方法**：手动编辑项目目录下的 `config.yaml`，将 `owners: null` 改为 `owners: [<你的用户ID>]`，然后重启 bot。

## 4. 默认条目

条目模板位于 `defaults/entries.yaml`，bot 首次加载时自动补全到 `config/permissions/entries.yaml`。

模板文件格式：每行一个列表 `[描述, users.is_white, [users.whites...], [users.blacks...], groups.is_white, [groups.whites...], [groups.blacks...]]`。

| 条目名 | 描述 | 默认行为 |
|---|---|---|
| `setu` | 是否允许使用获取二次元图片相关命令 | 群组白名单 `setu`（仅私聊），用户无限制 |
| `nsfw` | 是否允许修改二次元图片 `-r` 选项 | 用户/群组白名单 `nsfw`（仅私聊） |
| `mutlisetu` | 是否允许一次获取多张二次元图片 | 群组白名单 `mutlisetu`（仅私聊），用户无限制 |
| `convert` | 是否允许使用 convert 命令 | 用户/群组白名单 `convert`（仅私聊） |
| `shitpost` | 是否允许使用 shitpost 命令 | 用户/群组白名单 `shitpost`（仅私聊） |
| `help` | 是否允许使用 help 命令 | 无限制 |
| `md2pic` | 是否允许使用 md2pic 命令 | 无限制 |
| `session` | 是否允许使用 session 命令 | 无限制 |
| `otherwise` | 错误命令输入后是否提示 | 无限制 |
| `perm` | 是否允许使用 `/perm check` | 无限制 |
| `permmanager` | 是否允许使用 `/perm` 管理命令 | 用户/群组白名单（空），需手动添加管理员 |

## 5. 开发者指南

### 命令中添加权限检查

在 `BotCommand` 的子类 `run()` 方法中调用：

```python
if not self._check_perm("<条目名>"):
    await self.send_msg("权限不足")
    self.unlock()
    return
```

`_check_perm` 定义于 `command.py`，自动从 session 获取 `group_id` 和 `user_id`。

### 添加新权限条目

1. 在 `defaults/entries.yaml` 中添加一行，格式为 `[描述, users.is_white, users.whites, users.blacks, groups.is_white, groups.whites, groups.blacks]`，如以下例子所示：
   ```yaml
   叮咚鸡: ["大狗叫", false, ["兴奋剂"], ["banned"], true, ["见缸马"], ["banned"]]
   ```
2. bot 重启后，若 `config/permissions/entries.yaml` 中不存在该条目，则自动补全。
