# /pixiv

**根据Pixiv ID从P站获取图片**

## 使用方式

```bash
/pixiv [选项] <Pixiv ID>
```

## 选项

| 选项 | 说明 |
|------|------|
| `-r <模式>` | 内容模式，默认为 `off` |
| `-s <质量>` | 图片质量，默认为 `regular` |

### 内容模式

| 模式 | 说明 |
|------|------|
| `off` | 启用内容过滤 |
| `on` | 关闭内容过滤（仅私聊可用） |

### 图片质量

| 质量 | 说明 |
|------|------|
| `regular` | 普通质量 |
| `original` | 原图质量 |

## 示例

```bash
/pixiv 88326528                   获取 松うに 的 ミクさんの日2021 的普通质量图片
/pixiv -s original 46840684       获取 舘津テト 的 う…うるさい！ 的原图质量图片
/pixiv -r on 43935647             获取 KOTSU 的 (出るよ) 的普通质量图片, 不对其内容进行过滤 (仅限私聊)
```

## 注意

- `-r on` 仅限私聊使用
