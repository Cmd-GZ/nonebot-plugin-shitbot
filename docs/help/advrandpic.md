# /advrandpic

**随机获取二次元图片，支持标签筛选**

## 使用方式

```bash
/advrandpic [选项]
```

## 选项

| 选项 | 说明 |
|------|------|
| `-n <数字>` | 设置发送图片数量，范围 1~10，默认为 1 |
| `-r <模式>` | 内容模式，默认为 `off` |
| `-s <质量>` | 图片质量，默认为 `regular` |
| `-t <表达式>` | 标签筛选表达式，默认为空（不筛选） |

### 内容模式

| 模式 | 说明 |
|------|------|
| `off` | 启用内容过滤 |
| `on` | 关闭内容过滤（需要 `nsfw` 权限条目通过） |
| `only` | 仅发送被过滤的内容（需要 `nsfw` 权限条目通过） |

### 图片质量

| 质量 | 说明 |
|------|------|
| `regular` | 普通质量 |
| `original` | 原图质量 |

## Tag 表达式写法

- `|` 表示"或"：`萝莉|少女` → 有萝莉或少女的标签就行
- `&` 表示"与"：`白丝&黑丝` → 同时有白丝和黑丝的标签才行

**混合使用时，`|` 优先结合**：`萝莉|少女&白丝|黑丝`
1. 先处理 `|` 得到 `(萝莉|少女)` 和 `(白丝|黑丝)`
2. 再用 `&` 连接，相当于 `(萝莉|少女) 且 (白丝|黑丝)`
3. 最终效果：有(萝莉或少女) 且 有(白丝或黑丝)

### 限制

- 最多 3 个 `&`，最多 20 个 `|`
- **请勿使用括号**，不会改变优先级，还可能让表达式无效

## 示例

```bash
/advrandpic                   获取 1 张图片
/advrandpic -n 3 -s original  获取 3 张原图
/advrandpic -n 5 -t 萝莉|少女&白丝|黑丝
    获取 (萝莉 或 少女) 且 (白丝 或 黑丝) 的图片，共 5 张
```

## 注意

- `-r on` 和 `-r only` 需要 `nsfw` 权限条目通过的情况下才可使用
