# /randpic

**随机获取二次元图片并发送**

## 使用方式

```bash
/randpic [选项]
```

## 选项

| 选项 | 说明 |
|------|------|
| `-n <数字>` | 设置发送图片数量，范围 1~10，默认为 1 |
| `-r <模式>` | 内容模式，默认为 `off` |

### 内容模式

| 模式 | 说明 |
|------|------|
| `off` | 启用内容过滤 |
| `on` | 关闭内容过滤（仅私聊可用） |

## 示例

```bash
/randpic         获取 1 张图片
/randpic -n 3    获取 3 张图片
```

## 注意

- `-r on` 仅限私聊使用
