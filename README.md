# Shitbot

这项目目前是我自用的QQ机器人插件，正在逐步完善中

## 已实现的功能

- 调用ffmpeg将图片转成视频，使得某些由于各种原因在群里发不出去的图片可以以视频的形式发送

- 随机二次元图片

- 半自动搬史
